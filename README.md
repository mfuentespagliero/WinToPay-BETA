# WinToPay BETA

E-commerce experimental que mezcla compras online con una experiencia de juego interactiva.

## Sobre el proyecto

WinToPay nace como una prueba de producto digital donde el usuario puede interactuar con un minijuego para desbloquear beneficios dentro de una tienda online.

## Funcionalidades

- Juego tipo buscaminas
- Sistema de puntos
- Cronómetro
- Catálogo de productos
- Diseño responsive
- Interfaz visual personalizada

## Tecnologías

- HTML
- CSS
- JavaScript
- GitHub Pages
- Cloudflare
- Nic Chile
